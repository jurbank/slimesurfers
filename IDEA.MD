# Basically Splatoon but in space, on spherical planet bodies. Teams will come later, free for all will be the first / default mode

- Colyseus for multiplayer
- THREE.js for 3d / game engine

# Requirements
- We will build from an "online-first" approach.
- Configuration is critical to testing.

# Scaleability
- follow best online battle arena practices as the game will scale quickly
- follow robust architecture patterns to maintain maximum ease of understanding and project maintenance
- files should not blow up to thousands of lines of code

# Features

- player is an alien blob
- splatoon like mechanic where the alien is trying to spread their slime across the planets
- 3rd person camera
- player starts on it's planet, can take fly to other planets

## Input

- wasd keys
